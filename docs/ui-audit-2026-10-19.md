## Final root causes found during regression

- **UI-004, tablet:** the intermediate two-column grid made the third service span both columns while keeping a fixed-height stage. Optical review caught a cropped laptop. Normal wrapping and a reserved 16:9 stage now preserve composition at 600, 900 and 1000px. Intermediate/final crops are retained under `ui-evidence/media-review/`.
- **UI-029/034, locale navigation:** retained root layouts left `html.lang` stale after client navigation. Header now synchronizes the document language to its resolved locale. Native keyboard language selection verifies the URL, preserved enquiry context and document language.
- **UI-027, collapsed draft sections:** a requirement link could focus a field inside closed recipient details. `focusRequirement` now opens ancestor disclosures before focusing; 390/1440px tests verify it without saving or issuing anything.
- **UI-030, labels:** project filters/alt captions inherited inline label geometry. Shared visual rules now separate visible labels from controls. The transparent native file-input hit area is intentionally excluded from text-gap measurement, not hidden by a test-only rule.
- **UI-005, test setup:** synthetic seed content was published by default. The synthetic-only fixture script now defaults to private drafts; `--published-media` is an explicit isolated media-test option. Zero-published state and private-default seeding both passed. Production binding/publication remains uninspected.
- **Images:** responsive candidates now follow the capped card widths and distinct 80–140px related thumbnails. Home/About intrinsic declarations match the unchanged 1600×900 originals. No editorial assets were replaced.

Final acceptance status, exceptions, precise evidence and reproducible commands are in [ui-regression-report.md](ui-regression-report.md). New refinement files are checkpointed separately; `ui-evidence/working-tree-delta.patch` records only this pass's incremental edits to existing dirty files and is already applied.
